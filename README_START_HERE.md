פתח `dist/Rafael_Brothers_M474_ENCOUNTER_LAYOUT.html` בדפדפן. HTML עצמאי, ללא שרת.

Enter מתחיל; חצים לתנועה; Space לקפיצה; J לפטיש; E לחיבור/שחרור סרט המדידה; למעלה/למטה לכוונון הסרט; Tab להחלפת דמות; K למקדחה לאחר איסופה; R לאתחול; F3 לטלמטריה וייצוא JSON.

הגזע הראשון כעת אובייקט אחד: אזהרה, שבירה, סיבוב, התייצבות ומשטח ביניים. J מפעיל אותו דרך הפטיש המקורי. השורשים הירוקים התלויים אינם פלטפורמות. מפגש הגזע השני כבוי כברירת מחדל ומסומן parked בלוח; הוא נשאר זמין לבדיקות ואינו חוסם סיום. כל האתגרים המזרחיים נשמרו.

קרא את M474_QA_REPORT.md למגבלות הראיות. M474_VISUAL_COMPARISON.html מציג צילומי לפני/אחרי באותה מצלמה, כולל שלבי נפילה שהוקפאו לצורך הצילום בלבד. סרטוני בדיקה אנושיים לא הומצאו; רצפי המקלדת אוטומטיים.

בנייה: `npm test`, `npm run build`. לבדיקות דפדפן נדרשים Playwright/Chromium ו־requirements-qa.txt. הגדר `CHROMIUM_PATH` ו־`QA_PYTHON` לפי סביבתך. `npm run qa:all` מפעיל רצף בדיקות ושער שחרור; `npm run qa:release` דורש ראיות עם חתימות תואמות ולא יוצר אותן.

Rollback מלא ללא דריסה: `python3 scripts/rollback-to-m473.py /new/destination`. הכלי יוצר תיקייה חדשה בלבד, משחזר את כל948 הקבצים המקוריים ומאמת כל SHA-256. החבילה המקורית שהעלית נשארה ללא שינוי. מסמכי M473 וקובצי HTML היסטוריים נשמרים כהיסטוריה, ולא כאישור לגרסה הנוכחית.
