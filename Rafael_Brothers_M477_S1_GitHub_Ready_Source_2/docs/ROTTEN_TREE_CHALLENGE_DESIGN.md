# האחים רפאל — Rotten Root / Hollow Tree Challenge

**סטטוס:** רעיון שאושר לתכנון כאתגר חוזר. **לא מומש במשחק בגרסת M4.6.1**; מוצג בסרגל כ־Planned בלבד.

## התפיסה
עץ חלול, שורש נגוע או גזע רקוב שנראה חלק מהיער. לעיתים השחקן גורם לקריסה, ולעיתים ניתן לזהות אותה מראש. בהמשך מתברר שחלק מהעצים רוקנו על ידי טרמיטים — רמז אורגני לסיפור ולמלך הטרמיטים. באזורים הראשונים חלקם רקובים באופן טבעי, בלי לחשוף מיד את כל האיום.

## וריאציות הניתנות למיחזור
- `partial_break`: חלק מהקליפה נשבר, חושף חלל, ולעיתים פותח מעבר סודי או מאפשר להשתמש בגזע כפלטפורמה.
- `total_fall`: הגזע מתערער ונופל אחרי התרעה; יכול לחסום מעבר זמנית או ליצור גשר חדש. הגשר החדש אינו קיצור דרך אוטומטי לבור Ninja Rope של S01.
- `termite_hollow`: מנהרות, נסורת, חורים בדפנות; בהמשך ניתן לאכלס בטרמיטים קטנים (מודול נפרד), ולשלב תזמון של קריסה ואויבים.

## State machine מומלץ
`intact` → `telegraph` (0.6–1.1 שניות התרעה) → `fracture` (0.25–0.5 שניות) → `fallen_partial | fallen_full` → `spent`. מעבר `reset` מכל מצב אל `intact` במוות, restart או טעינת שלב. טריגרים בהתאם לסוג: דריכה ממושכת, פטיש J, מקדחה K, מפסק/אויב או timer גלוי. אין קריסה אקראית בלי אות ברור לשחקן.

## קריאות ומשחקיות הוגנת
סדקים, אבקה/נסורת שמתפזרת מהחורים, רעד קל של הגזע וחריקה. התרעה נראית גם כשהקול כבוי. ההשפעה על השחקן יכולה להיות נפילה או חסימה זמנית, אך לא מוות בלתי נמנע או מלכודת שלא ניתן לזהות. פיזיקה ופגיעות עקב קריסה נבדקות בשני המצבים — רפי ושאול.

## ממשק ועיצוב נתונים
```json
{
  "id":"root-trap-01",
  "kind":"rotten-tree",
  "variant":"partial_break",
  "trigger":"weight|hammer|drill|timer",
  "warningMs":750,
  "position":{"x":0,"y":0},
  "oneShot":true,
  "resetOnRespawn":true,
  "enabled":true
}
```

כל `stageId` יוכל לכלול `rotten-tree` בתצורת JSON, עם קואורדינטות ומצב טריגר משלו. שליטה דרך `Stage Modules` תתווסף **רק אחרי מימוש ובדיקות**, ולא כמתג דקורטיבי לא פעיל. להפריד `Simulation` דטרמיניסטית מ־`Phaser` render/collision ולשמר את מנוע Arcade הקיים, גוף השחקן ואת Ninja Rope.

## QA חובה בעת מימוש
1. לכל וריאציה: intact → warning → break → aftermath; אין כפילות אירועים.
2. כיבוי בזמן התרעה/קריסה, restart, מוות ושינוי stage — ניקוי נכון של גוף ההתנגשות, timers ואפקטים.
3. התנגשות לא נעלמת לפני ההתמוטטות ולא נשארת אחרי שהגזע כבר אינו דריך.
4. גזע נופל אינו נועל את השחקן בתוך הקרקע או מעל הבור ללא פתרון.
5. רפי, שאול, J, K, E, מצב Manual/Classic/Hybrid, spiderlings, sticky web, FPS.
6. עשר ריצות דטרמיניסטיות + תרחישי קצה: התנגשות בכניסה, חבל מחובר, respawn תוך הקריסה, רצף טריגרים כפול.

**המלצת תזמון:** לבנות אבטיפוס עצמאי במיילסטון ייעודי אחרי סיום M4.6.1, ולהתחיל ב־`partial_break` כמלכודת סביבתית פשוטה. לא חייב להמתין לאנימציות הדמויות אם נשמרת הפרדת מערכות.
