## בנייה ובדיקה
- `npm test` — בדיקות Node.
- `npm run build` — HTML מה־Stage JSON ומהמקור המודולרי.
- `npm run qa:negative` — הוכחת חסימת העוגן השגוי ושחזור.
- `npm run qa:all` — הבדיקות המלאות לפי הסדר, ואז שער שחרור לפי חתימות.
- `npm run qa:release` — בודק ראיות עדכניות; אינו ממציא ראיות ואינו מריץ אותן מחדש.

לבדיקות דפדפן: התקן את devDependencies ואת `requirements-qa.txt`, וספק `CHROMIUM_PATH` ו־`QA_PYTHON` לפי הסביבה. נדרש Chromium מקומי תקין. `npm install` / `python3 -m pip install -r requirements-qa.txt`; התקנת הדפדפן יכולה להתבצע באמצעות Playwright בסביבה רגילה.
