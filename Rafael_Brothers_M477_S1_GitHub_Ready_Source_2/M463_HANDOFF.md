## Test instructions

1. Open game and inspect the original forest, ambient gnats, mist, and root bridges. All should appear unchanged.
2. With tape equipped, hook near the spawn (living tree); from near x330 before pit, original x514 root should be chosen; on far side near x810, the bridge root should be available.
3. In Stage Modules > Hazards, try `Rotten root / hollow tree` near the end: stand on the rotten shelf or pull its anchor. Hear cracking, see warning, then collapse. It resets on R.
4. Switch **Falling Tree** ON (off by default), then stand on the rotten stub near the left pit lip. After cracks it falls into a **short partial bridge**. You must still use the tape to reach the far bank.
5. Switch falling tree OFF to restore the previous clean challenge; it removes both new collision and its anchor.
6. Toggle bridges OFF while attached to the new stable bridge anchor: tape releases safely; turning bridges on makes it available again.
