- Stage v1 additive `collapsing-platform`: stable-log, rotten-log, crumbling-bridge variants. Compiles independent ID, position, footprint, contact delay, warning duration, outcome and anchor refs.
- One managed collection at SceneComposer root; each instance owns its own ResourceScope, collider/body/graphics/binding/state clock and create/update/disable/reset/destroy methods. Destroying one unbinds only its ID; restart reconstructs all authored instances. No timer or input listener per instance.
- Teaching recovery rearm is an explicit Stage Challenge recovery policy, triggered by real grounded return to the stable entry, not a global unconditional reset.
- Historical rotten-root and falling-bridge-tree sources remain byte-identical. No rope forces, body movement or jump formulas changed. Original two gaps and approved hook coordinates remain.
- Ceiling Spider retains original sidecar patch and state machine. A narrow enabled guard gates AI/damage/hammer, owned view visibility and reset; one button controls the existing enemy. No second spider is spawned.
- Crossing snapshot includes explicit one-way-top collision policy from the new live Phaser bodies. Upward reel samples can pass through one-way surfaces, matching the actual collider predicate; full solids still block. This validator remains conservative and finite, not a whole-trajectory proof.
- Formal JSON schema now declares `ropeCrossings`, which the M472 loader already supported but the historical schema omitted. Both old/new JSON pass the repaired additive schema.
- Stage authored eastern world extends to3020; visible recovery floor and third challenge gap are new. Original gaps370–706 and1190–1270 are retained. Exit geometry derives only from JSON.
- Historical fixed-layout tests run against the preserved M472 Stage fixture. No cases were deleted. New tests cover the actual M473 data and authorized panel change. Old preservation tests compare the frozen historical panel; the current panel is separately constrained to the precise removal of the always-on note.

No new enemy assets, no Stage02, no automatic composer, no Forge plugin modification. Full source and immutable original M472 archive are included.
